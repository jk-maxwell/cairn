Cairn / drawing set / draft 3 2026-08-18  ·  twelve plates

The surface, drawn before the engine.

Three surfaces carry five capabilities. If they cannot make the four daily journeys feel simple, the plugin has failed before any code exists, which is the cheapest possible place to fail. Everything here is a proposal. Nothing here is built.

Changes from draft 2: integration moves to arrival, on one work queue that dreaming drains at idle and Dream now drains on demand, blocking, with progress; the vault ratified as the whole integration boundary, daily notes included; import reports and the task ledger drawn as notes; export cut to Markdown; the yield wording made plain; two instruments killed; Plate K, navigation and nothing else; and Plate L, the ecosystem drawn as data.

How to review

Numbered notes, plate letter plus key number. B4 is the fourth annotation on the Ask plate. A kill note kills it.

What is transcribed

Unmarked annotations restate a journey or a thesis rule already ratified. Arguing with those is arguing with the thesis.

What is proposed

Anything carrying new is invented here rather than transcribed. All are listed at the foot, with the ones already ratified marked.

What is missing

No colors, no icon set, no type choices for the plugin itself. Layout and behavior only, so the argument stays about the journey.

Plate A

The key

Six marks appear on every plate that follows. They are the product's vocabulary made visible, and each one exists because a thesis rule needs a place to show itself on screen.

The cut

Personal. Yours, current, irreplaceable. Never rewritten, only annotated.

Reflection. A snapshot of something that lives elsewhere. Always cited with its date.

Derived. Summaries, descriptions, embeddings. Regenerable, never a source of truth.

Confidence, three levels

Strong Moderate Weak

Retrieval not run

A fact about this answer, right now, and it dies with the answer. A chip with a dot always means confidence and never anything else. Shown before the prose finishes, so belief is never invested ahead of the evidence.

Provenance

Generated Ratified 2026-08-14

Snapshot 2026-05-02

A fact about an artifact, forever, and it never washes out. Stamps never share a row with confidence chips, so the two facts can never be read as one.

The three tiers

Ratified. Asks every time. Anything that asserts meaning.

Journaled. Acts, then shows its work. Mechanical upkeep only.

Forbidden. No affordance exists anywhere in the interface.

Verbs, not chrome

Cairn adds three panes and a handful of commands. Everything else is Obsidian's own idiom: the palette, drag and drop, context menus.

Ctrl Cmd shown per platform, never hard coded

Cross platformnew

Windows, Linux, and macOS are equal targets, so no screen names a mechanism only one of them has. Modifier keys render per platform, paths render in the platform's own form, and every connector affordance has a plain file path behind it.

Test that can fail

Someone who has read nothing but this plate can look at any later plate and say, for any element on it, which cut it belongs to, whether it is a proposal or a record, and whether Cairn may touch it unattended.
